## Featured project

### [Lens: explainable resume screening](https://github.com/Mohit1473/lens) · [Live demo](https://lens-xr1e.vercel.app)

![Lens in motion](https://raw.githubusercontent.com/Mohit1473/lens/main/docs/screenshots/web-motion.gif)

Lens ranks resumes against a job description and shows exactly why each candidate scored
the way they did, with quotes from the resume as evidence. A person always makes the
final decision.

- **Explainable scoring:** 65% skills, 20% keywords, 15% text similarity, all visible
- **Review queue:** suggested rejections with reasons, confirmed by a person
- **Hiring pipeline:** drag candidates from New to Hired, with notes, ratings and email drafts
- **Fairness built in:** blind screening, and experience is shown but never scored
- **Two apps:** a Next.js web app on Vercel and a Python Streamlit dashboard over 4,700 demo resumes

`Python` `scikit-learn` `pandas` `Streamlit` `Next.js` `React` `TypeScript` `Vercel` `GitHub Actions`
